What Is This Project?

PneumoVision is an educational medical imaging tool that uses Artificial Intelligence to analyze chest X-ray images and detect signs of pneumonia.


The system combines two AI technologies:

  • 🧠 CNN Model — scans and classifies your X-ray as NORMAL or PNEUMONIA
  • 🤖 LLM Chatbot — answers medical questions about symptoms, treatment & recovery
⚠️ This is an educational tool only — not a clinical diagnostic device. Always consult a qualified doctor.
🛠️

Development Process

1
Data Collection

Used the Kaggle Chest X-Ray Images dataset containing thousands of labeled chest X-rays split into NORMAL and PNEUMONIA categories.

2
Data Preprocessing

All images converted to grayscale and resized to 224×224 pixels. Pixel values normalized to 0–1 range. Class imbalance handled using class weights.

3
Data Augmentation

Applied rotation, width/height shifts, shear, zoom, and horizontal flip using ImageDataGenerator to improve generalization and prevent overfitting.

4
Model Architecture (CNN)

Designed a custom 4-block CNN with Conv2D layers, BatchNormalization, MaxPooling, and Dropout layers from scratch using Keras Sequential API.

5
Training

Trained for up to 15 epochs using Adam optimizer (lr=0.0001) with EarlyStopping and ModelCheckpoint callbacks to save the best model.

6
Evaluation

Evaluated on the test set using Accuracy, Precision, Recall, AUC-ROC score, Confusion Matrix, and ROC Curve visualization.

7
Deployment

Built a web interface using Flask (HTML/CSS/JS frontend) and integrated Groq Cloud AI (LLaMA 3.3 70B) for the medical chatbot assistant.

🏗️

CNN Model Architecture

Developed entirely using TensorFlow / Keras — a custom CNN built from scratch, not a pretrained model.

📸 Input: 224 × 224 × 1 (Grayscale)
↓
Conv2D (32 filters) + BatchNorm + MaxPool
↓
Conv2D (64 filters) + BatchNorm + MaxPool
↓
Conv2D (128 filters) + BatchNorm + MaxPool
↓
Conv2D (128 filters) + BatchNorm + MaxPool
↓
Flatten → Dropout(50%) → Dense(512) → Dropout(30%)
↓
Dense(1, Sigmoid) → NORMAL / PNEUMONIA
🎯 Accuracy: 87%
📈 AUC-ROC: 95.2%
⚖️ Loss: Binary Crossentropy
🔧 Optimizer: Adam
